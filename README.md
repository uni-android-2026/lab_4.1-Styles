# Практическая работа №4.1

## Описание
Эта работа посвящена созданию общего стиля и его повторному использованию для нескольких элементов интерфейса.

## Что было сделано
1. Подготовлена разметка с текстовыми блоками и кнопками.
2. В файл `styles.xml` вынесен общий стиль для `TextView`.
3. Один и тот же стиль применён к нескольким текстовым элементам на экране.
4. Подписи элементов оформлены через строковые ресурсы.
5. Для активности настроена тема, соответствующая общей стилистике приложения.

## Результат
Получился пример, демонстрирующий, как сократить дублирование в разметке и централизованно управлять оформлением элементов.
